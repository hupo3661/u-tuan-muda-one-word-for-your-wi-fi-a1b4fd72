One word for make.fun's "One Word for Your Wi-Fi" bounty: the single word that describes Wi-Fi best — "Buffering". It is what Wi-Fi does whenever you need it most, and as a network name it is a joke that tells the truth about itself. `main.py` writes the word to `/output/entry.txt`, deterministically, with no network and no randomness.

## Run it

```sh
python3 main.py
```

The word is written to `/output/entry.txt` (override with `OUTPUT_PATH`).
